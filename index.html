在 GitHub 匯入（Import）外部儲存庫主要有兩種常見方法：使用 GitHub 內建的匯入工具（GitHub Importer） 或透過 命令列（Command Line）。

方法一：使用 GitHub 網頁匯入工具（GitHub Importer）

適合從 GitLab、Bitbucket 或其他 Git 服務輕鬆搬遷整個專案與 Commit 歷史紀錄。

  1. 登入 GitHub，點擊右上角的 + 按鈕，然後選擇 「Import repository」（匯入儲存庫）。
  2. 在 「Your old repository's clone URL」 欄位中，輸入你要匯入的舊儲存庫的 Clone URL（例如 HTTPS 或 Git 連結）。
  3. 在 「Owner」（所有者） 與 「Name」（名稱） 欄位設定新倉庫的擁有者與名稱。
  4. 選擇隱私設定（Public 或 Private）。
  5. 如果該外部倉庫是私有（Private）的，請輸入該服務的帳號與存取認證（例如 Bitbucket 的 App Password 或 GitLab 密碼）。
  6. 點擊 「Begin import」（開始匯入），等待系統處理完成後會收到 Email 通知。

詳細說明可參考 GitHub 官方匯入工具文件。

方法二：透過命令列（Command Line）匯入

適合熟悉 Git 指令、或需要更靈活控制推送過程的情況。

  1. 建立一個空的 GitHub 倉庫：
    在 GitHub 建立一個新的空白 Repository（不要勾選 Initialize this repository with a README、license 或 gitignore）。
  2. 在本地端鏡像複製（Bare clone）舊的儲存庫：
    打開終端機（Terminal / Command Line），執行： 
    git clone --bare https://external-host.com
  3. 推送到新的 GitHub 儲存庫：
    進入該目錄並使用 --mirror 將所有分支與標籤推送到 GitHub： 
    cd old-repo.git
git push --mirror https://github.com
  4. 清理本地暫存的 bare 專案（可選）： 
    cd ..
rm -rf old-repo.git

詳細步驟可參考 GitHub 官方命令列匯入文件。
